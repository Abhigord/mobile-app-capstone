# User Stories

1. As a user, I want to register with email and password so that I can create a new account.
2. As a user, I want to log in with my credentials so that I can access the app.
3. As a user, I want to view a list of tasks on the home screen so that I can see all my tasks.
4. As a user, I want to tap on a task to view its details so that I can see more information.
5. As a user, I want to add a task to favorites so that I can quickly access important tasks.
6. As a user, I want to view my favorite tasks so that I can see them in one place.
7. As a user, I want to fetch tasks from an API so that I can see updated data.
8. As a user, I want to change app settings so that I can personalize my experience.
9. As a user, I want to receive notifications so that I am reminded of my tasks.
